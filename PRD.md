# Project: HiddenLink (Stealth QR Logos)
## PRD - Version 1.0 (March 26, 2026)

### 1. Vision
Transform every business logo into an interactive, invisible portal. High-end brands no longer have to choose between aesthetic beauty and digital functionality.

### 2. User Personas
- **The Modern Marketer**: Wants to increase engagement on physical assets (packaging, business cards).
- **The Luxury Brand Manager**: Refuses to put "ugly" QR codes on expensive products.
- **The Event Planner**: Wants a "magic" moment for guests.

### 3. Core Features (MVP)
1. **Logo Generator**: Upload logo + URL -> Generate AI-textured stealth logo.
2. **Dynamic Routing**: Dashboard to change the URL without changing the image.
3. **Scan Validation**: Built-in automated checker to ensure the AI-generated logo is actually readable.
4. **Physical World Optimization**: Specialized models for high-contrast/high-durability printing (Vehicle wraps, signage, storefronts).
5. **Analytics**: Real-time tracking of scan counts and locations.

### 4. Technical Stack
- **AI Infrastructure**: Stable Diffusion + ControlNet (QRCode Monster).
- **Backend/Scaling**: Google AntiGravity (Functions & Cloud Run).
- **Database**: Firestore (to store dynamic link mappings).
- **Frontend**: React/Tailwind (Modern, dark-themed dashboard).

### 5. Monetization
- **Free**: 1 Static Logo.
- **Pro ($29/mo)**: Unlimited Dynamic Links + Premium Textures (Gold, Glass, Neon).
- **Agency ($199/mo)**: Multi-client management + API Access.
