# HiddenLink Frontend

Modern, dark-themed React frontend for the HiddenLink stealth QR engine.

## Features
- **Mission Control Aesthetic**: Dark slate and electric indigo theme.
- **Drag-and-Drop Logo Upload**: Supports PNG and JPG.
- **Side-by-Side Preview**: Compare original link vs stealth link appearance.
- **Live Generation**: Connects to Google Cloud Function API.

## Tech Stack
- React
- TailwindCSS
- Lucide-react Icons
- Axios
- Framer Motion

## Deployment
This project is ready for deployment to Vercel or Firebase.
To build for production:
```bash
npm run build
```
